### المرحلة 2: النشر على Render

#### Bot 1:
1. Create Web Service
2. Repository: repo الخاص بك
3. Build: `pip install -r requirements.txt`
4. Start: `python bot.py`
5. Environment: 
   ```
   DATABASE_URL=postgresql://...
   ```

#### Bot 2:
1. Create Web Service جديد
2. Repository: نفس الـ repo
3. Build: `pip install -r requirements.txt`
4. Start: `python bot2.py`
5. Environment:
   ```
   DATABASE_URL=postgresql://... (نفس الـ DB)
   ```

## 💰 مثال على تغيير الأسعار:

### في Bot 2:
1. اضغط 🔐 لوحة الادمن
2. اختر ⚙️ تغيير سعر البائع
3. اختر البائع
4. اختر المنتج
5. اختر المدة
6. أدخل السعر الجديد

**النتيجة**:
- البائع "أحمد" الآن له سعر مختلف
- لا يؤثر على الأسعار الأخرى
- كل بائع سعره الخاص

---

## 🎨 مثال على تصميم البائع:

### في Bot 2:
1. اضغط 🔐 لوحة الادمن
2. اختر 🎨 تصميم البائع
3. اختر البائع
4. اختر ما تريد تعديله:
   - 🎨 اللون: `#FF5733`
   - 📝 الرسالة: "مرحباً في متجري!"
   - 🔘 الأزرار: `premium`
   - 📸 اللوجو: رابط الصورة

**النتيجة**:
- البائع "علي" له هويته الفريدة
- لون أزرار مختلف
- رسالة ترحيب خاصة به

## 📞 الدعم الفني:

### المشاكل الشائعة:

#### ❌ "ModuleNotFoundError: psycopg2"
```bash
pip install psycopg2-binary==2.9.10
```

#### ❌ "Database connection error"
- تحقق من DATABASE_URL
- تأكد من DB نشط

#### ❌ البوت لا يرد
- تحقق من TOKEN
- تأكد من الإنترنت
